# 🤖 CodeBot - Basic Python Chatbot

A simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Description

CodeBot is a console-based chatbot that interacts with users through predefined responses.

The chatbot can understand common inputs such as greetings, questions about its name and capabilities, requests for the current time and date, and commands such as help and exit.

This project demonstrates fundamental Python programming concepts including:

- Variables
- Strings
- Lists
- Conditional statements
- Loops
- Functions
- User input and output
- Exception handling
- Date and time handling

## ✨ Features

- 👋 Greeting responses
- 😊 Responds to "How are you?"
- 👤 Provides the chatbot's name
- 📚 Explains what the chatbot can do
- 🕐 Displays the current time
- 📅 Displays today's date
- 🤖 Multiple predefined responses
- ❓ Handles unknown questions
- 🔄 Continuous conversation
- 📋 Help command
- 👋 Goodbye/exit command
- ⚠️ Basic error handling

## 🛠️ Technologies Used

- Python 3
- `datetime` module
- VS Code
